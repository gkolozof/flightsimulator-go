SEO + Cloudflare + Analytics setup
==================================

1. GOOGLE SEARCH CONSOLE
   - https://search.google.com/search-console
   - Add property: https://flightsimulator.gr
   - Verification: put the code in index.html meta name="google-site-verification"
   - Submit sitemap: https://flightsimulator.gr/sitemap.xml

2. GOOGLE ANALYTICS 4
   - GA4 Measurement ID: G-BKCQ86LGR1 (already set in js/main.js)
   - It loads only after the visitor accepts analytics cookies
   - Analytics loads ONLY after the user accepts cookies (GDPR)

3. CLOUDFLARE
   - SSL/TLS: Full (strict) recommended
   - Speed: Auto Minify (HTML/CSS/JS), Brotli ON
   - Caching: Standard; respect existing headers
   - robots.txt and sitemap are already set for this path (/go/)
   - Optional: Page Rules / Cache Rules for /go/img/* long cache

4. AFTER DEPLOY
   - Hard refresh
   - Test cookie banner (Accept / Reject / Settings)
   - In Search Console: request indexing for homepage + /go/products/
   - Optional: Bing Webmaster Tools + same sitemap

5. INSTALL
   cd /var/www/html/flightsimulato.gr/go
   unzip and copy contents of fs-final/ here
   chown -R www-data:www-data .
